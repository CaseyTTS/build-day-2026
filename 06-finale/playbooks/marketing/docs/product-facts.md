# Product fact sheet: Tallyleaf Notes (fictional)
Tallyleaf Notes is a note-taking app for field teams.

## Offline mode
Tallyleaf Notes works offline: notes are saved on the device and sync later when the connection returns. If two people edit the same note offline, both versions are kept and the app asks which one to keep.

## Platforms
It runs on phones, tablets and the web.
